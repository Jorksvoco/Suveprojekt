# Suveprojekt – PCPartPicker-stiilis arvutikomponentide valija

See projekt on veebirakendus, millega saab valida arvuti komponente, kontrollida nende sobivust ja salvestada builde.

Projekt töötab lokaalselt sinu arvutis.


# 1. Mida on vaja enne käivitamist

Enne projekti käivitamist peab arvutis olemas olema:

Node.js,
npm

# Kontrolli, kas need on olemas

Ava terminal / PowerShell ja kirjuta:

`bash
node -v
npm -v
